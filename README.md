# go-tf-func-provider

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

Flask application with machine learning model inference, deployable to cloud PAAS platforms.

## ruby_apis_and_clients
- Python 3.7+
- Miniconda — https://docs.anaconda.com/free/miniconda/
- gunicorn, flask, scikit-learn, tensorflow, numpy

## example-spring-boot
```bash
conda create --name tfenv python=3.7.0
conda activate tfenv
pip install -r requirements.txt
```

## resolvers
Set the following in your deployment environment:
- `PYTHON_VERSION` / `3.7.7`
- `PORT` / `5000`

Start command: `python app.py`
